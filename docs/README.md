Pages come in three kinds: **concepts** (the general idea, no board needed), **modules** (one topic as built here, usually runnable) and **case studies** (one failure, from symptom to fix). The catalog, the learning path, the system page and the navigation block at the end of each page are generated by `tools/gen_docs.py`; `tools/check_content.py` verifies every reference.
